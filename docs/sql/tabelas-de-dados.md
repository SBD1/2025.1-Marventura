# Tabelas de Dados

Abaixo serão listados os itens que estarão presentes no Banco de Dados do **Marventura**. É importante notar que os itens que possuem efeito são itens **consumímeis**. Todos os itens consumíveis possuem um ou mais efeitos, assim como os acessórios. Logo, os itens que **não** possuem efeito estarão na tabela de **itens não consumíveis**.
Os itens que são encontrados no mapa não são encontrados nas lojas e, portanto, não possuem preço de compra. Já as armas e os acessórios não poderão ser vendidos, por isso não possuem preço de venda.
